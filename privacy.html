Privacy Policy

Last updated: 6 October 2026

Overview

Quote Compare Assistant is a skills-only plugin developed by Marco Colussi. It does not operate a separate developer-controlled backend, user-account system, or database for processing plugin requests.

Information handled

The plugin may be used with text, documents, quotes, estimates, bids, proposals, prices, quantities, supplier information, and other content that a user chooses to provide in the host product.

Developer collection and storage

The developer does not intentionally receive, store, maintain, sell, or create an independent copy of user content submitted to the plugin through a separate developer-controlled server or database.

Processing by the host platform

User interactions and uploaded content may be processed by the platform on which the plugin is used, such as ChatGPT or Codex, according to that platform's own terms, privacy policy, settings, and data-retention practices. Those practices are controlled by the platform provider, not by the developer of this plugin.

Third parties

The current version of Quote Compare Assistant does not send user content to developer-operated third-party services or external APIs.

Data retention

Because the developer does not operate a separate backend or database for this plugin, there is no separate developer-controlled retention period for plugin content.

Security

No method of electronic processing is completely secure. Users should avoid providing information that is unnecessary for comparing quotes and should follow the security guidance of the host platform.

Changes

If a future version introduces a backend, external service, analytics, authentication, or additional data collection, this policy will be updated before or alongside that change.

Contact

For privacy questions, contact mc.agent.plugin@gmail.com.
